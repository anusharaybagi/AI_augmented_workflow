# AI-Assisted Software Development Workflow

## Project Overview

This project focuses on using Artificial Intelligence as a support tool during the software development process. The application was created in Python with assistance from AI-based coding tools.

## Aim of the Project

The main aim is to study how AI can support programmers in different stages of development. It can help in writing code, understanding programming concepts, finding mistakes, and making the development process more efficient.

## Tools and Technologies

* Python programming language
* GitHub for project management
* AI-based coding assistance tools
* Visual Studio Code for development

## Files Included

The project contains the following important files:

* `main.py` – Contains the primary Python code of the application.
* `README.md` – Provides information and instructions about the project.
* `contribution_log.md` – Keeps track of the code created with AI assistance and the work completed or changed by the developer.

## Role of AI

AI was used as a development assistant throughout the project. It helped in suggesting code, explaining programming concepts, locating and correcting errors, and making improvements to the existing program.

A separate contribution log is maintained to clearly identify the sections where AI was used and the portions that were developed or modified manually.

## Steps to Execute the Project

1. Make sure Python is installed on the computer.
2. Download the project or clone the GitHub repository.
3. Open the downloaded project directory.
4. Execute the `main.py` file using Python.
5. View the program results in the terminal.

## Final Outcome

The project shows that AI can be effectively used as a programming assistant during software development. At the same time, maintaining a contribution record helps distinguish between AI-supported work and the developer's own contribution.
